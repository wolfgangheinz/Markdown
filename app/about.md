# About Markdown Studio

Markdown Studio was created by [Wolfgang Heinz](https://wolfgangheinz.com). It is a local-only Markdown editor for secure editing on your own computer, with no installation required.

## Use it fully locally

1. [Download the ZIP](https://github.com/wolfgangheinz/Markdown/archive/refs/heads/main.zip).
2. Unzip the download and keep the `app` folder beside `index.html`.
3. Open `index.html` in your browser. Write in the Markdown pane and see the result in the preview. Drafts save in your browser; use **File → Save** to download a Markdown file.

Markdown Studio is a free, open source project by Wolfgang Heinz. Find the source on [GitHub](https://github.com/wolfgangheinz/Markdown). Contributions are welcome.
